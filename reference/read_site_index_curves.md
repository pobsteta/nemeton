# Read the site-index reference curves

Returns the full table of reference site-index curves shipped with the
package, with a per-session cache. The CSV is generated by
`data-raw/site_index_curves.R`.

## Usage

``` r
read_site_index_curves()
```

## Value

A `data.frame` with columns `species, age, class_1, ..., class_5`.
Heights in metres.

## Examples

``` r
curves <- read_site_index_curves()
head(curves)
#>   species age class_1 class_2 class_3 class_4 class_5
#> 1    QUPE  10    3.33    2.98    2.54    2.11    1.76
#> 2    QUPE  15    5.66    5.07    4.32    3.58    2.98
#> 3    QUPE  20    8.07    7.22    6.16    5.10    4.25
#> 4    QUPE  25   10.46    9.36    7.98    6.60    5.50
#> 5    QUPE  30   12.76   11.42    9.74    8.06    6.72
#> 6    QUPE  35   14.95   13.38   11.41    9.44    7.87
```
