# Get allometric key for a species class

Get allometric key for a species class

## Usage

``` r
get_allometric_key(species_code, region = "BFC")
```

## Arguments

- species_code:

  Character. NMT species class code.

- region:

  Character. Region code. Default "BFC".

## Value

Character. Allometric key (e.g., "Quercus", "Fagus", "Pinus").
