# RAG knowledge base for AI perspectives (E7 / spec 009)

Retrieval-Augmented Generation primitives for the \`nemeton\` core:
ingest forestry documents into a vector store, embed queries, and
retrieve the most relevant passages so that the AI perspectives
generated by \`nemetonshiny\` can cite verifiable sources.

The subsystem is \*\*opt-in\*\*: the knowledge tables are created by
\[enable_rag()\], not by the default \[db_migrate()\] sequence, because
the PostgreSQL backend needs the \`pgvector\` extension which is not
guaranteed on every deployment (ADR-012).

Two storage backends are supported transparently, mirroring the
monitoring subsystem:

\* \*\*PostgreSQL + pgvector\*\* – \`embedding\` is a \`vector(3072)\`
column and \[retrieve_knowledge()\] runs an exact cosine KNN via the
\`\<=\>\` operator. \* \*\*SQLite\*\* – \`embedding\` is a JSON array in
a \`TEXT\` column and the cosine similarity is computed in R. Fine for a
single-project corpus (a few thousand chunks).

Embeddings are produced by a configurable provider: Mistral (default,
ADR-004 souverainete FR), OpenAI, or Voyage AI (Anthropic ecosystem).
All three expose an OpenAI-compatible \`/embeddings\` endpoint.
