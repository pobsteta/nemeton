# RECONFORT deciduous (OSO 2021) binary mask registry entry

Metadata for the default broadleaf mask used by the RECONFORT
map-production step: file size and MD5 used by
[`ensure_reconfort_oso_mask`](https://pobsteta.github.io/nemeton/reference/ensure_reconfort_oso_mask.md)
to verify a fetch. The mask is the OSO 2021 deciduous-tree layer
redistributed in the upstream repository (\`fl.mouret/reconfort\`,
Apache-2.0).

## Usage

``` r
RECONFORT_OSO_MASK
```
