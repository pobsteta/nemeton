# Default trustworthy RECONFORT classes for garde-fou G1

The dieback classes that
[`list_alerts`](https://pobsteta.github.io/nemeton/reference/list_alerts.md)
keeps by default — the RECONFORT mirror of FORDEAD's \`c("3-forte",
"4-sol-nu")\`. The healthy class \`1-sain\` is always excluded.

## Usage

``` r
RECONFORT_ALERT_CLASSES
```
