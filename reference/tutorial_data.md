# Tutorial datasets downloaded on demand (tutorials 07 and 08)

The LiDAR datasets used by the \`07-lidar-advanced\` (\`aba.model\`, ~97
MB) and \`08-coregistration\` (\`coregistration\`, ~3.4 MB) tutorials
are kept in the git repository (\`inst/extdata/aba.model/\`,
\`inst/extdata/coregistration/\`) but excluded from the package build
(\`.Rbuildignore\`). An installed package therefore does not ship them:
\`.tutorial_data_dir()\` returns a local copy, downloading the missing
files once into the nemeton cache.

\*\*Source URL.\*\* Files are fetched from the raw files of the GitHub
repository at the tag of the installed version:
\`https://raw.githubusercontent.com/pobsteta/nemeton/v\<X.Y.Z\>/inst/extdata/\<dataset\>/\<file\>\`.
A development version (\`X.Y.Z.9000\`, no tag) reads branch \`main\`.
The file list, sizes and MD5 sums come from
\`inst/extdata/tutorial_data_manifest.csv\` (regenerated by
\`data-raw/tutorial_data_manifest.R\`); every download is checked
against them.

\*\*Cache.\*\* \`file.path(get_global_cache_dir(), "tutorials", \<ref\>,
\<dataset\>)\`, one folder per tag so versions never mix. Set
\`NEMETON_CACHE_DIR\` to move it.

\*\*Offline.\*\* If a file cannot be downloaded, the call stops with an
explicit error naming the dataset, the URL and the manual way out (copy
\`inst/extdata/\<dataset\>\` from a clone of the repository into the
cache folder).

In a source checkout (or under \`devtools::load_all()\`), the data are
found under \`inst/extdata/\` and nothing is downloaded.

## Usage

``` r
.tutorial_data_dir(
  dataset = c("aba.model", "coregistration"),
  cache_dir = get_global_cache_dir(),
  ref = .tutorial_data_ref(),
  use_local = TRUE,
  quiet = FALSE
)
```

## Arguments

- dataset:

  Character(1). \`"aba.model"\` (tutorial 07) or \`"coregistration"\`
  (tutorial 08).

- cache_dir:

  Character. Cache root. Defaults to \[get_global_cache_dir()\].

- ref:

  Character. Git reference (tag or branch). Defaults to the tag of the
  installed version (\`main\` for a development version).

- use_local:

  Logical. Use \`inst/extdata/\<dataset\>\` when the package provides it
  (source checkout). Default \`TRUE\`.

- quiet:

  Logical. Suppress progress messages. Default \`FALSE\`.

## Value

Character(1). Path of a local directory holding the dataset.
