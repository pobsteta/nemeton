# Canonical RECONFORT classes by target species

Per-species ordered class labels of the Random-Forest output (spec 021
§4.4). Index \`i\` (1-based) is the class for the integer code \`i\` in
the classification raster (code \`0\` is no-data/masked, it has no
label). Oak (\`CHE\`) and chestnut (\`CHT\`) have 3 classes; Scots pine
(\`PS\`) has 2.

## Usage

``` r
RECONFORT_CLASSES
```
