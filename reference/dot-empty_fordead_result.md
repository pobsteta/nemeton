# Build the structured return value for \[run_fordead_dieback()\]

Build the structured return value for \[run_fordead_dieback()\]

## Usage

``` r
.empty_fordead_result(
  output_dir,
  python_env,
  status = "success",
  duration_sec = NA_real_,
  fordead_version = NA_character_,
  message = NA_character_,
  zone_id = NA,
  n_scenes = 0L
)
```
