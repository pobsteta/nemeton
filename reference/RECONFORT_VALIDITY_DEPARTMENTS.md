# Department codes covered by the RECONFORT calibration validity zone

INSEE codes of the six departments of the Centre-Val de Loire region
where the RECONFORT model is calibrated: Cher (18), Eure-et-Loir (28),
Indre (36), Indre-et-Loire (37), Loir-et-Cher (41), Loiret (45).

## Usage

``` r
RECONFORT_VALIDITY_DEPARTMENTS
```
