# Free-form causes proposed in the QGIS form

These are \*suggestions\* presented to the field observer. The chosen
value lands in \`alert.validation_cause\` verbatim — the \`alert\` table
does not enforce a CHECK constraint on this column (see migration
\`0001_initial_v1.sql\`).

## Usage

``` r
HEALTH_VALIDATION_CAUSES
```

## Lifecycle

Experimental: may change in any release, without deprecation (spec 057).
